# Doom Dork
An open source launcher and WAD manager for Doom on Windows.

## Choose your engine
- Doom Dork is compatible with all modern Doom engines including:
    - Chocolate Doom
    - DSDA Doom
    - GZDoom
    
## Choose your IWAD
- No IWADS are provided with Doom Dork so you'll have to supply them yourself. You don't need all of them, but depending on your mod, you will need the compatible IWAD that supports it.
    - DOOM.WAD
    - DOOM2.WAD
    - HERETIC.WAD
    - HEXEN.WAD
    - strife1.wad
    - voices.wad (Used with Strife)

## Choose your mod
- Add local WADs or browse from the web
